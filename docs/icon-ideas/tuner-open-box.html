okibasho 箱チューナー

等角の開いた箱をスライダーで調整する。フラップの長さと角度、線の太さ、紙、床の円い置き場所（任意）を変えると、5 状態のアニメーションと 96 / 48 / 24 / 16px の見え方が同時に更新される。箱は毎フレーム 3D 座標から描いているので、クリックすると本当に一回転する。決まったら下の SVG とパラメータをコピーして使う。
